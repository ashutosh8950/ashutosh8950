### 📰 Fake News Detector

A machine learning based fake news detection system that classifies articles using NLP preprocessing, TF-IDF features, and ensemble ML models.

<p align="center">
  <img src="https://raw.githubusercontent.com/ashutosh8950/ashutosh8950/main/assets/fake-news-detector-dashboard.png" width="88%" alt="Fake News Detector Dashboard" />
</p>

**Tech Stack:** Python, Scikit-learn, FastAPI, NLTK, TF-IDF, Ensemble ML, Render

**Highlights:**
- Trained 5 ML models on 40K+ articles with accuracy-weighted ensemble voting achieving ~99.3% accuracy
- Built NLP pipeline using lemmatization, stopword removal, title weighting, and bigram TF-IDF
- Created FastAPI endpoints for analysis, health check, and model information
- Deployed with a dark-mode frontend and animated confidence gauges

### 🛡️ ShieldAI Fraud Detection System

A real-time transaction fraud detection system that predicts fraud severity and shows alerts through a dashboard.

<p align="center">
  <img src="https://raw.githubusercontent.com/ashutosh8950/ashutosh8950/main/assets/fraud-detection-dashboard.png" width="88%" alt="ShieldAI Fraud Detection Dashboard" />
</p>

**Tech Stack:** Python, Flask, Scikit-learn, Random Forest, SQLite, JavaScript, Chart.js

**Highlights:**
- Trained Random Forest model on 10K transaction records with behavioral transaction features
- Achieved 97%+ accuracy and 0.99 ROC-AUC
- Used StandardScaler pipeline and class-weight balancing for imbalanced fraud data
- Built Flask REST APIs for real-time prediction and alert persistence
- Designed dashboard with live KPIs, Chart.js analytics, and animated risk gauge
