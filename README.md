## Experience

### AI Trainee — Virves Software Solutions

Internship work focused on a multi-document validation workflow for Aadhaar, PAN, and Driving License uploads. I built a FastAPI backend with Tesseract-first hybrid OCR, EasyOCR fallback, OpenCV preprocessing, document-type detection, identity-field extraction, explainable decision outcomes, applicant tracking, manual-review APIs, and MongoDB/GridFS persistence.

The workflow used staged OCR candidates, resizing, rotation/crop deduplication, targeted field OCR, capped OCR calls, and early exits to reduce redundant processing. The source code and identity-document data remain private; the public portfolio presents the architecture and validation approach without exposing sensitive records.
